# SFX assets

Place these audio files here (e.g. WAV or MP3). The app will use them when present and fall back to procedural sound if missing or on error.

| File | When it plays |
|------|----------------|
| **confirm_click.wav** | CONFIRM_1: user presses ACCEPT or DECLINE (dry click) |
| **crystal_reveal.wav** | Crystal ball camera feed fades in (one diegetic sound) |
